## 暫定解釈（手順2のデータ移行で確定させる）

1. **odds_taken**：オッズ欄が数字だけ（例 `1.14`）の場合は取得オッズとみなした。レンジ・「約」・「以上」・「未確認」は `null`。
2. **推奨取引の重複6組**（詳細IDの組）：`detail-log-barca-rec/detail-log-barca`、`detail-lat-ger-rec/detail-lat-ger`、`detail-charlton-city-rec/detail-cha-mci`、`detail-smr-fin-rec/detail-smr-fin`、`detail-ag-lgd-rec/detail-ag-lgd`、`detail-fearx-cyb-rec/detail-fearx`。
3. **data-ts にオフセットがない6行**（ODDIK、リヨン、イタリア、Bounty Hunters、コリンチャンス、チュニジア）は JST とみなした。
4. **VALUE の開始時刻**は表示文言から読み取った。Karmine Corp は開始時刻の記載がないため `null`。
5. VALUE② の「VALUE②採用」は本成績（`adopted`）、「VALUE②監視」は参考成績とした。
